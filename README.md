# 📊 Customer Data Analysis using SQL & Power BI

> An end-to-end Data Analytics project that analyzes retail customer transactions using **SQL** and **Power BI** to uncover customer behavior, sales trends, payment preferences, and business insights.

---

## 📌 Project Overview

This project demonstrates the complete data analytics workflow, from SQL-based data analysis to interactive Power BI dashboards.

The analysis focuses on:

- Customer purchasing behavior
- Revenue analysis
- Product category performance
- Payment method analysis
- Age group analysis
- Gender distribution
- Shopping mall performance

---
